Decision Drift Lab

Can a sequence of reasonable-looking decisions produce an outcome that betrays the original objective? Compare Jev and an OpenAI LLM using identical options, independently accumulated histories, and two policy framings.

API key privacy and independent verification: We do not intentionally store, retain, or log API keys on this server or include them in published experiment results. Keys are kept in your browser tab’s session storage and passed through the application server only to submit live model requests. Because the server must process requests, its operator could technically access submitted keys; we cannot guarantee that hosted requests are unreadable to the operator. 06 / Independent decision review
